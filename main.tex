\begin{block}{Abstract}
  The Dark Sky Protection Program aims to establish long-term monitoring of sky brightness at several sites of interest to NOIRLab.
  We present an open-source Python package for acquiring and managing data from SQM-LE and TESS-W4C devices, 
  together with supporting components, yet to be released, that enable their autonomous operation at geographically distributed locations. 
  The system is designed for robust, unattended operation, with resilience to communication, hardware, and software failures. 
  These capabilities provide a scalable infrastructure for long-term characterization of sky brightness and its evolution at astronomical sites. 
  % In this poster we focus on the \verb=dspp-reader= Python package, which provides a unified interface for data acquisition, calibration, and storage.
\end{block}

\begin{block}{The Hardware}
  \begin{center}
    \imageslot{img/photometers.png}{0.92\linewidth}{Image placeholder\\
      (\texttt{skyimage.jpg}: photo of the device / all-sky image)}
    \vspace{0.4cm}

    {\itshape Figure 1. Arrangement of pairs of SQM-LE and TESS-W4C photometers aimed at several key locations. This particular setup is located at Cerro Pach\'on, Chile.}
  \end{center}
  The photometers provide network interfaces over Ethernet (SQM-LE) and Wi-Fi (TESS-W4C), respectively, using TCP/IP for network communication. 
  This allows us to setup nodes that request a reading from the photometers and then safely send the data to a datacenter.
\end{block}

    the data collection interval, and the output directory for storing the collected data.
